Run on demand (serverless)

Works on the Render web service (or Vercel) with the CRON_SECRET token from the Environment tab.

Deployment methods

  1. Manual - python src/pipeline.py --workers 4 or run_pipeline.bat
  2. Scheduled - Render Cron Job, render.yaml, daily 02:00 UTC
  3. Web service - Render runs server.py: this dashboard + /api/run
  4. Serverless - Vercel Function api/run.py, Vercel Cron 06:00 UTC
  5. CI - GitHub Actions runs pytest on every push / pull request

Rollback

  1. Platform: promote the last good deployment (Render / Vercel Instant Rollback)
  2. Code: git revert <bad-sha>, push, CI re-tests and redeploys
  3. Data: restore outputs from the previous run backup
  4. Full plan in ROLLBACK_PLAN.md
